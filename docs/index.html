How a request becomes a decision

  1. A request arrives

    The API takes a pre-deal check or a book of trades.

  2. Work fans out

    Redis Streams feeds workers that KEDA scales.

  3. C++ does the maths

    The same scenarios price the book before and after the trade.

  4. A decision comes back

    A rate, a charge, a verdict. Cassandra keeps the record.
