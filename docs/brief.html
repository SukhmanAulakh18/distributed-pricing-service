Distributed Pricing Service

A front-office pricing and CVA platform in miniature: a C++20 Monte Carlo library behind a Python service, distributed across Kubernetes worker pools on Redis Streams and Cassandra, managed in Rancher, observed end to end, and run through chaos tests that kill pods, databases and a whole node under load.

Financial engineering

  • Black-Scholes, European and arithmetic Asian Monte Carlo with antithetic variates, a geometric control variate and pathwise Greeks
  • Exposure engine: correlated GBM, EE, PFE (exact top-k merge), EPE and unilateral CVA
  • Every model tested against an independent reference (textbook values, parity, closed forms)

Distributed systems

  • Redis Streams with consumer groups, reclaim of dead workers' tasks, poison handling, separate intraday and batch priority
  • Counter-based RNG keyed by request hash: exact sharding, safe caching, idempotent re-runs
  • Cassandra modelled query-first (RF 3, LOCAL_QUORUM, token-aware), written behind

Reliability and SRE

  • SLOs with multi-window burn-rate alerts; 14 alerts, each with an owner and a runbook link
  • Chaos runs that found three real problems; fixes measured; one still open and documented
  • OpenTelemetry traces across processes; runbook with 14 incidents; triage CLI

Platform and DevOps

  • 4-node kind cluster over 3 zones, imported into Rancher; PDBs, zone spread, 30 s eviction
  • KEDA scaling on queue lag (batch from zero), HPA for the API; Kustomize base and overlays
  • CI: C++ (GCC, Clang), Python, ASan/UBSan, TSan, Valgrind, kubeconform, promtool, amtool
